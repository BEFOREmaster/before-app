# BEFORE — Google AI 키 1개로 끝내는 월 0원 배포 패키지

2026년 7월 네이버 개발자센터의 검색 API가 종료/이관됨에 따라, **Google AI Studio 키(`AQ.`) 딱 1개만** 넣으면 Gemini의 실시간 Google Search 연동으로 유튜브·네이버·구글 후기와 최저가까지 한 번에 분석하도록 업그레이드했습니다!

## 5분 무료 배포 순서
1. [GitHub](https://github.com/)에서 새 저장소(`before-app`) 생성 후 압축 푼 파일 전체 업로드
2. [Vercel](https://vercel.com/)에서 GitHub 로그인 → `before-app` Import
3. **Environment Variables**에 딱 1줄만 추가:
   - `GEMINI_API_KEY` = 대표님이 발급받은 `AQ.` 키
4. **Deploy** 클릭 → 1분 뒤 생성된 주소로 폰에서 바로 실행!
